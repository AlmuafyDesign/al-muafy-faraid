# আল মুয়াফি — ফারায়েজ হিসাব

বাংলা-প্রধান, অফলাইন-সক্ষম ফারায়েজ হিসাব ও সিরাজী দলিল পাঠাগার। অ্যাপটি কোনো অ্যাকাউন্ট বা সার্ভার ব্যবহার করে না; হিসাব ব্যবহারকারীর ব্রাউজারেই সংরক্ষিত থাকে।

## ব্যবহার

GitHub Pages বা যেকোনো static hosting-এ repository-র root প্রকাশ করলেই অ্যাপটি চালু হবে। `index.html` মূল পৃষ্ঠা। `data/siraji.json` পাঠাগার এবং হিসাব-সংশ্লিষ্ট আরবি দলিলের তথ্য রাখে।

## প্রযুক্তি

- Vanilla HTML, CSS ও JavaScript
- IndexedDB-তে স্থানীয় হিসাব সংরক্ষণ
- Progressive Web App এবং Service Worker
- কোনো build step বা backend নেই
